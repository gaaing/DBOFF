## 二、刚刚截图报错的精准清除

1. **`ERROR: Can't open file from path 'res://assets/tex/texture/character/a_hfi_m_boots001.png'` 与 `a_mmi_m_boots001.png`**：
   - **根因**：素体模型（`a_hum_m_ad.glb` 与 `a_maj_m_m.glb`）此前导出的贴图相对目录被指定到了 `character/` 目录，而项目中这些公共皮肤/靴子贴图真实存放在 `assets/tex/texture/item/` 下。
   - **修复**：全量重新校准并导出了 5 套成人素体，所有纹理 URI 100% 指向 `../../../tex/texture/item/` 下的真实文件。
   - **核验**：经全量模型扫描，`mesh_pc` 目录下所有 GLB 模型内部均已不再包含任何指向 `texture/character/` 的失效链接，红字错误彻底归零。
