## 终极根因剖析与解决机制

### 1. 为什么角色头上会出现巨大的黑色“人字形折叠长杆/折叠架”？为什么衣服和裤子都不显示？
- **现象表现**：
  在创角与大厅界面中，人类、那美克、魔人武道家等角色身上衣服、裤子、靴子消失，只露出素体裸身（纯色皮肤 + 白色底裤），同时头顶和背后悬空伸展出一个巨大的黑色折叠架。
- **根本原因排查**：
  1. 武道家初始手部武器为 `500001`（`w_glv_16_m_m.glb`，深黑金属色拳套，包含双手网格）；初始防具为道服上装、裤子与靴子。
  2. 装备模型导出为 GLB 时，根节点直接由 50 根无父子级的平面节点（`nullroot`, `Bip01`, `Bip01 Pelvis` ...）和网格节点组成，场景中**不存在名为 `Skeleton3D` 的节点**。
  3. Godot 4 的 `GLTFDocument` 在没有 `Skeleton3D` 节点时，`own_skin.get_bind_name(i)` 永远返回空字符串 `""`。
  4. 导致代码在遍历装备的 50 根骨骼时，每一根骨骼的 `b_name` 全为 `""`，`skeleton.find_bone("")` 全部返回 `-1`！
  5. 代码全部进入 `else` 分支：将整套装备的全部 50 根骨骼**强制绑定到同一个骨骼 `Bip01 Pelvis`（盆骨）**，并且把逆绑定姿态粗暴替换为 `skeleton.get_bone_global_rest(fallback_b_idx)`（盆骨全局正向姿态）！
  6. **灾难性后果**：
     - 上衣、裤子、靴子的所有网格顶点全部塌缩至盆骨一点，缩进身体看不见；
     - 黑色双手拳套网格顶点受到双重正向变换倍增拉扯，从盆骨跨越头顶撕裂伸展成巨大的黑色“人字形折叠长杆”！
- **修复方案**：
  1. 新增 `DBOCharacterFactory.get_glb_joint_names(glb_path)`：直接读取 GLB 头部 20 字节与 JSON Chunk，解析 `skins[0].joints[i]` 对应的节点真实名称（如 `Bip01 L Hand`, `Bip01 R Hand`, `Bip01 Pelvis`, `Bip01 Spine` 等），内存字典极速缓存，100% 准确获取 50 根原生骨骼名。
  2. 骨骼逐一精准匹配至素体 `Skeleton3D`；若遇特定种族特有骨骼（如裙摆 `B_SK_`、头触角 `B_M` 等），执行定向归属映射。
  3. 彻底恢复 `new_skin.set_bind_pose(i, own_skin.get_bind_pose(i))`，保留导出的数学上绝对正确的逆绑定矩阵，网格完美复原。

### 2. 儿童素体与装备穿戴架构对齐
- **用户核心准则**：
  1. 儿童素体本身就是没有装备时的裸身状态（纯色皮肤 + 底裤）；
  2. 装备是独立的 3D 模型挂载在素体之上；
  3. 儿童可以使用缩小道具或在童年期穿戴所有装备（包括儿童专属装与全量成人装备）。
- **落实情况**：
  1. **儿童素体保护**：`character_visual.gd` 严格保护儿童素体底裤（`pants000`）与各部位纯色皮肤（`pants_skin`, `jacket_skin`），魔人男童粉红肤色着色器实时同步，素体绝不挖空断肢。
  2. **装备独立外挂**：外部防具与武器网格挂载在骨架上，网格紧密包裹素体。
  3. **装备多体型支持**：优先路由磁盘存在的 880 个原生儿童装备（`A_*CH`）；当使用缩小道具穿戴成人装备时，因保留原生骨骼绑定与逆绑定姿态，骨架线性蒙皮（LBS）自然依据儿童骨骼尺寸适配，绝无撕裂穿地。

### 3. 为什么“丢失左手，两个手套叠在右手”？
- **原版资产特性**：
  RenderWare DBO 1.69 原版客户端资产中，所有对称武器（手套 `W_GLV_*`）和靴子（`A_*_B_*`）在 DFF 中只建模了右侧网格：
  `w_glv_16_h_m.glb` 仅包含 147 个顶点，且仅绑定至右臂骨骼（`Bip01 R Forearm`, `Bip01 R Hand`, `Bip01 R Finger*`）。
- **双重缺陷叠加**：
  1. 素体双手在素体 Mesh 中位于同一表面。旧代码在检测到穿戴手套时，直接将素体手部表面设置为 `inv_mat`（全隐形）；
  2. 手套模型又仅有右侧，导致左手彻底失去任何模型和材质支持，形成严重的“空气断手”！
  3. 右手戴着一个厚重深黑拳套，左手光秃秃消失，用户误认为“两只手套都叠到了右手”。
- **解决方案实施**：
  1. 在 `character_factory.gd` 中实现 `_mirror_single_sided_mesh_if_needed`：检查装备网格若仅使用右侧骨骼（包含 ` R `）且缺失左侧骨骼（不含 ` L `），自动通过 `ArrayMesh` 沿 X 轴翻转顶点（`x = -x`）、法线与切线，反转三角面索引缠绕顺序（`i0, i2, i1`），并将右侧骨骼索引映射至左侧骨骼（`Bip01 R Hand` -> `Bip01 L Hand` 等），生成完整的左右双手拳套与左右双脚短靴；
  2. 在 `character_visual.gd` 中保留素体手部表面的真实皮肤材质，彻底消灭断肢。

### 4. 为什么“无法正确显示新手装备，底裤往下应该是裸露的腿的部分被不知名贴图糊住了”？
- **根本原因**：
  旧代码在 `_resolve_item_glb_path` 中，遇到儿童角色时粗暴通过 `_get_child_armor_model_candidates` 拦截，将官方新手道服（如 `A_HFI_04_01_J`、`A_HFI_04_01_P`）强行改为了 `A_HCH_J_H_M` 和 `A_HCH_P_H_M`。
  而 `A_HCH_P_H_M` 实际是儿童素体下半身（白色底裤 + 双腿连体网格），材质直接使用了白色底裤贴图 `a_hum_m_pants000.png`。
  把素体下半身当做裤子挂载，导致整个双腿全部被白色内裤贴图糊满；同时上衣被替换为光膀子素体，角色呈现光膀子+白腿的怪异状态。
- **解决方案实施**：
  彻底废除 `_get_child_armor_model_candidates` 拦截，直连加载官方真实的新手道服防具模型（`a_hfi_04_01_j_h_m.glb`、`a_hfi_04_01_p_h_m.glb`、`a_hfi_04_01_b_h_m.glb`），显示原汁原味的红蓝道服与长裤。

### 5. 澄清“缺少魔人男童装备”真相与那美克素体膨胀消除
- **魔人男童装备真相**：
  魔人男童官方新手道服：
  `A_MMI_04_01_J` -> `assets/obj/item/mesh_armor_majinmale/a_mmi_04_01_j_m_m.glb`
  `A_MMI_04_01_P` -> `assets/obj/item/mesh_armor_majinmale/a_mmi_04_01_p_m_m.glb`
  `A_MMI_04_01_B` -> `assets/obj/item/mesh_armor_majinmale/a_mmi_04_01_b_m_m.glb`
  资产库中**完全存在、毫无缺失**！此前误判是因为旧拦截逻辑去寻找根本不存在的儿童内衣 `A_MCH_J_M_M`（魔人男童素体全身一体，无独立 J 内衣）。解除拦截后魔人男童装备完全正常显示。
- **消除那美克素体膨胀**：
  此前由于将素体 `A_NCH_J_N_O` 和 `A_NCH_P_N_O` 当作装备穿在已有素体 `namek_m_child.glb` 之上，导致三层素体网格叠加产生不自然膨胀。恢复独立防具外挂后彻底解决。
