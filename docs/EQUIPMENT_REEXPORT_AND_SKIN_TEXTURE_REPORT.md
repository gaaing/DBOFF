## 二、核心故障深度剖析与技术解决方案

### 1. 为什么裤子模型只能看见内部贴图，看不见表面贴图？
- **故障现象**：在选角界面中，裤子的外部表面如同透明空气，玩家视线穿透外皮只能看到裤子内侧背面的反向贴图。
- **底层计算机图形学根因（三角面缠绕顺序逆转与背面剔除）**：
  在 RenderWare 3.x 官方二进制规范中，`RwTriangle` 的结构体定义为：
  ```c
  struct RwTriangle {
      RwUInt16 vertex2;   // 偏移 0 字节 (t[0])
      RwUInt16 vertex1;   // 偏移 2 字节 (t[1])
      RwUInt16 matIndex;  // 偏移 4 字节 (t[2])
      RwUInt16 vertex3;   // 偏移 6 字节 (t[3])
  };
  ```
  在 glTF 2.0 / OpenGL / Vulkan / Direct3D 规范中，**正面朝向摄像机的三角形必须按逆时针（Counter-Clockwise, CCW）排列**，即 `(vertex1, vertex2, vertex3)`。
  - 此前导出脚本中错误写入了：
    ```python
    mat_groups.setdefault(m, []).append((t[0], t[1], t[3]))
    ```
    这里传入的索引是 `(vertex2, vertex1, vertex3)`，交换了顶点 1 和顶点 2！
  - **严重后果**：这导致三角形的右手螺旋定则方向完全倒转为顺时针（Clockwise），所有三角面的几何表面法线全部朝向角色身体内部（朝向骨骼，点积计算全部为负值：$-0.3295$）！
  - 当 Godot 4 默认开启背面剔除（`cull_mode = CULL_BACK`）时，摄像机从角色正前方观察时，所有朝外的表面三角形因为法线背向摄像机而被**全部剔除丢弃**；而只有从缝隙看进去时，背对摄像机朝向内侧的三角面才会被画出来！
- **修复方案**：
  1. 彻底修正导出器中的三角面索引组装为正规逆时针：
     ```python
     # t[1] 是 vertex1, t[0] 是 vertex2, t[3] 是 vertex3
     mat_groups.setdefault(m, []).append((t[1], t[0], t[3]))
     ```
  2. 验证点积测试：校准后，裤子全部 296 个三角面的法线与顶点法线点积为正数（$+0.3295$），**朝外正面比例达到绝对 100.0%**！
  3. 全量重导出覆盖全部 8,185 个模型，所有道具模型正面法线彻底归正。
