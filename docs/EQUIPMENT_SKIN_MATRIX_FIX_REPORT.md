# DBOFF 装备与素体蒙皮矩阵拉伸缺陷修复报告

## 一、问题背景

在角色创角与角色选择大厅中，角色装备（道服、裤子、靴子）以及素体出现严重几何撕裂拉伸成巨大三角形贴在地面上的问题，同时控制台伴有 `inv_binds_arr.size() != joints.size()` 以及贴图路径缺失报错。

---

## 二、根本原因定位

1. **RpSkin 逆绑定矩阵（Inverse Bind Matrix）偏移量计算偏差**：
   - 原 DFF 导出脚本使用 `len(sdata) - (num_bones * 64)` 计算逆绑定矩阵首地址；
   - 实际上 RenderWare `RpSkin` 结构体尾部包含 12 字节的扩展字段（`boneLimit`, `numSkinFrames` 等），导致逆绑定矩阵的首地址偏差了 12 字节（正好错位 3 个 float）；
   - 所有 4x4 逆绑定矩阵的 16 个 float 全量移位，导致 Godot 读入的逆绑定矩阵彻底崩塌，顶点被拉向虚空。
2. **骨骼层级与索引未按原版素体对齐**：
   - 原脚本使用通用的硬编码 50 根骨骼名称列表，与原版素体（Human M: 50, Human F: 52, Namek: 54, Majin M: 50, Majin F: 57）的标准骨骼层级与顺序不一致；
   - 导致如 `Bip01 Spine1`（胸口）的权重被错误链接到了 `Bip01 R Toe0`（右脚趾），引发袖子被扯向地面的折纸拉伸。
3. **成人素体 Joints 与 InvBinds 数量不匹配**：
   - 导致 Godot 引擎底层抛出 `Condition "inv_binds_arr.size() != joints.size()" is true` 并拒绝加载 GLB。
4. **UV 坐标标志位位运算掩码偏差导致索引越界（装备不显示根因）**：
   - 在解析 DFF `struct_chunk` 时，`has_uv` 误写为 `0x00040000` 而非 RenderWare 原生的 `0x0004`；
   - 导致包含纹理坐标的模型在解析时跳过了 UV 字节偏移，直接将 UV 的浮点数当成了三角形索引，产生高达 `16135` 的超大索引；
   - 触发 Godot 引擎 `Index indices_w[idx_i] = 16135 is out of bounds (orig_vertex_num = 350)`，导致全部装备加载失败、无法显示。
6. **儿童素体与成人防具冲突导致身体被挖空断截（魔人断腿/娜美克缺脚）**：
   - 之前逻辑在装备裤子/靴子/上装时，强制将素体对应的表面赋予全透明材质 `inv_mat`；
   - 在儿童素体上，由于没有独立的儿童 3D 防具，外挂成人防具会导致成人护腰/马甲遮挡不住儿童短小身材，且素体的真实双腿与脚部被全部隐形，直接造成魔人断腿悬空、娜美克缺脚、人类身体被吞噬；
   - 遵照 OpenDBO 源码规范：儿童素体自带完整初始道服与躯干，只有成人期角色（`is_adult == true`）才允许进行素体遮罩与外挂防具；儿童期角色防具由素体自身表现，仅挂载史考特与武器。
7. **史考特（Scouter）耳部贴合偏移**：
   - 修复了此前微调位置过深导致史考特陷进头骨内不可见的问题，重新校正为服帖外耳廓坐标。
