## 2. 深度根因分析 (Deep Root Cause Analysis)

### 问题一：鞋子为什么会长在脸上/脖子上（倒立围巾状）？
1. **致命镜像轴错误**：
   - 在旧代码 `_mirror_equipment_mesh` 中，为单侧靴子生成对侧几何体时，顶点生成逻辑错误地写成了：
     ```gdscript
     new_verts.append(Vector3(orig_v.x, -orig_v.y, orig_v.z))
     ```
   - 顶点的 Model Space 高度坐标 $Y$ 原本位于脚底（约 $-0.8$ 米）。取负后直接反转到了 $+0.8$ 米！$+0.8$ 米恰好位于角色的下颌、颈部与胸口位置！
   - 并且 $X$ 轴（左右）完全没有镜像，导致原本应该生成在左脚的靴子，不仅没有去左脚，反而倒立飞到了脖子和面部！
2. **彻底解决**：
   - 纠正为人体的左右对称（YZ 平面镜像），即翻转 $X$ 轴：
     ```gdscript
     new_verts.append(Vector3(-orig_v.x, orig_v.y, orig_v.z))
     new_normals.append(Vector3(-orig_n.x, orig_n.y, orig_n.z))
     ```
   - 骨骼权重准确重定向至对侧骨骼（`Bip01 L Foot` / `Bip01 L Calf` / `Bip01 L Toe0`），两只靴子完美稳稳踩在角色左右脚地面上。

### 问题二：编译解析错误导致下装丢失/悬空底裤（图 2、3、4、5）
1. **全局类与作用域中断**：
   - `character_visual.gd` 与 `character_factory.gd` 中存在局部变量名重名、作用域提升及未声明变量 (`joint_names` / `smat` / `m_name`)，导致 Godot 解析器在加载时报 `Parse Error`；
   - 脚本解析失败导致防具挂载管线无法执行，3D 裤子模型未生成，素体在材质互斥状态下判定错误，呈现悬空底裤（断腿）。
2. **彻底解决**：
   - 全面清理变量定义，规范静态类型标注；在工厂端增加完善的 `_resolve_child_pants_texture` 与 `_resolve_child_boots_texture` 贴图映射。

### 问题三：进入游戏时间直接下坠，世界似乎没有被正确加载
1. **坐标系与区块目录错位**：
   - 玩家角色存档中的大世界出生点坐标为 `x: 4975.6, y: -48.8, z: 4012.6`；
   - 但 `WorldChunkManager` 默认硬编码了 `zone_name = "start_001"`，该目录仅是一个 `-1024 ~ +1024` 的 8x8 小副本地图；
   - 且 `world_pos_to_chunk_coord` 中写死了 `clampi(..., 0, 7)`，直接将超出范围的 4975m 截断到了 (7, 7)；
   - 大世界的全量 3,337 个地表切片全部存放在 `data/terrain/chunks/` 中，全球网格转换公式应为：
     $$\text{col} = \lfloor(\text{pos.x} + 8192.0) / 256.0\rfloor = 51$$
     $$\text{row} = \lfloor(\text{pos.z} + 8192.0) / 256.0\rfloor = 47$$
   - 对应文件实为 `data/terrain/chunks/chunk_51_47.json`。由于找错目录与索引越界，系统在玩家脚下没有加载任何地形与物理碰撞体，玩家出生在无底虚空中，重力导致无限下坠！
2. **彻底解决**：
   - `WorldChunkManager` 自动根据坐标或地图模式切换全球大世界流式，采用全球 8192m 偏置公式，正确加载 `res://data/terrain/chunks/chunk_X_Y.json`；
   - 解除 `0..7` 的 clamp 边界限制，支持全图九宫格流式调度；
   - 在玩家加入场景前，先同步执行 `preload_area_sync(spawn_pos)`，确保脚下地表高度网格与 Jolt 物理碰撞体就绪；
   - 在角色基类中加入虚空坠落保护，彻底杜绝掉出世界。
