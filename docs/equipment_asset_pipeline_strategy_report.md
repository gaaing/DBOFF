## 二、 用户的四个核心疑问深度剖析

### 1. 重新提取是最好的方案吗？
**是的，这是彻底根治装备问题的唯一正统技术路线。**
- **当前现状**：`E:\DBOFF\assets\obj\item\` 现有的 GLB 是在早期以“静态物体”方式导出的，完全丢弃了 Chunk `0x116` 的骨骼与权重数据。因此，现有的防具挂在角色身上永远是一具不会动的死木偶（T-Pose）。
- **重提收益**：以 glTF 2.0 蒙皮规范（`JOINTS_0` + `WEIGHTS_0` + `inverseBindMatrices`）重新提取后，防具将原生具备随角色跑、跳、出拳、呼吸自然形变的能力。

### 2. 提取出来也能适用成人体型吗？
**完全适用，且成人是天然完美适配！**
- 原版 DBO 的 DFF 装备本身就是以**成年人体型作为标准绑定矩阵**建模的。
- 提取后的标准蒙皮 GLB 挂载在成人素体（`a_hum_m_ad` 等）上，与成人素体的 50 根骨骼 100% 对应，无需额外缩放，直接完美运转。
- **儿童体型如何适配？**
  原版儿童是二头身（短腿、短臂、大头）。旧工程成熟的技术是：在提取时读取 `character_bone_scales.json`，直接将儿童的骨骼缩放矩阵离线 Bake（烘焙）进顶点，输出一份专用于儿童的 GLB（存放于 `child/` 子目录）。这样**成人用标准版，儿童用烘焙版**，运行时完全解耦，零性能损耗，零骨骼错位。

### 3. 武器也需要提取吗？
**需要分类处理（手套必须重提，普通武器不必）：**
- **手套 (`w_glv_*`, 689 个)**：**必须重新提取为蒙皮网格**。手套在 DBO 中拥有 54 根骨骼（包含各指骨），出拳、握拳时必须形变。当前手套悬在空中平展正是因为被当成了刚体。
- **刀、剑、杖、斧、棍、枪 (`w_swd_*`, `w_stf_*` 等, 533 个)**：**不需要骨骼蒙皮！** 它们是纯刚体，当前现有的 GLB 已经可用，只需要在代码中通过 `BoneAttachment3D` 挂在 `nullRhand`（右手）或 `nullback`（背部），并在挂载儿童手中时缩放约 0.65 即可。

### 4. 时装也需要提取吗？
**绝大多数（95.6%）需要像防具一样重新提取为蒙皮网格。**
- 时装（Dogi、礼服、节日装等）穿在身上同样包裹了躯干与四肢，必须跟随骨骼弯曲。
- 只有 81 个时装帽子/假发属于刚体挂件，其余 1,759 个时装与常规防具在底层技术上完全一致。
