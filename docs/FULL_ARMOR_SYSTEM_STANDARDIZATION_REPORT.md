## 一、核心根因与精准修正对比

| 异常现象 | 历史代码病因 | 规范级修复方案 |
| :--- | :--- | :--- |
| **裤子掉落在左脚边堆成一团**（图1） | `_repair_equipment_left_side_bones` 误把左侧骨骼为 0 的顶点篡改覆盖为右侧对等骨骼，撕裂了原生双腿网格。 | **彻底废除对 `legs` 的任何网格篡改**。裤子本身即为双腿完备的网格，直接使用原生双腿骨骼驱动。 |
| **那美克星人胸前大尖突变形**（图2） | 成人上衣中的 `B_bust` 逆绑定矩阵平移与幼年儿童骨架高程不一致（2.04 倍位移差距）。 | 幼年期智能将 `B_bust` 骨骼平滑回退重定向到角色躯干主胸椎骨骼 `Bip01 Spine2`，完美贴合身体。 |
| **鞋子插在脖子里 / 翻转到地下**（图6） | 误将局部坐标系的高度轴 X（$0.22 \sim 0.53$m）当作左右轴沿 X 取负翻转，导致网格翻入负高程。 | 改用真正的横向左右对称轴 **Y 轴** 进行镜像（$X \to X, Y \to -Y, Z \to Z$），并反转面绕序与法线。 |
| **下半身断肢、悬空内裤**（图8） | 删除了幼年短路逻辑后，素体腿部被遮罩隐形，而裤子模型因材质丢失和网格破坏未正确渲染。 | 恢复裤子正规双腿加载，并加入 `_resolve_child_pants_texture` 全职业回退解析，双面渲染无剔除。 |
| **裤子只能看到内侧看不到表面** | 材质使用了默认背面剔除（`CULL_BACK`），而部分导出的三角形绕序为顺时针。 | 防具布料材质全量启用 `BaseMaterial3D.CULL_DISABLED`，`render_priority = 1`。 |
